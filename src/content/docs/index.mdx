## What is a TFM?

A **tabular foundation model (TFM)** learns from many prediction tasks during pretraining and can then make predictions on a new table.

To identify an iris species with an in-context model like TabPFN, give it flower measurements paired with known species (the **context**). Then give it the same kinds of measurements for a new flower whose species you want to predict (the **query**). The model uses the labeled examples to interpret the new row.

## What can a TFM do?

- **Classification:** Predict a category, such as an iris species. Some models return a probability for each class.
- **Regression:** Predict a number, such as material strength from processing conditions.
- **Uncertainty:** Some models estimate quantiles that can form a prediction interval. Check probability calibration or interval coverage on held-out data that reflect how you plan to use the model.
