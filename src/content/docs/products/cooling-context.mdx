Cooling Context is an instructional demo for building energy analysts preparing inputs for a tabular foundation model (TFM). It turns outdoor temperatures into degrees above a cooling reference and pairs them with occupancy, so the features reflect two drivers of cooling demand. When adapting to a new building, you can include its measured hours in the labeled context and set aside the hours you want to predict as unlabeled queries. Choose and run a model separately to obtain predictions.

## Tutorial

### Get access

<a href="/demos/cooling-context.py" download="cooling-context.py">Download cooling-context.py</a>

Save the script in a working folder. It uses the Python standard library; use Python 3.10 or later.

### Prepare an input

Save the following synthetic hourly readings as `readings.csv` beside the script. Keep the header exactly as shown.

```csv
split,temperature_c,occupancy_fraction,cooling_kwh
context,16,0.25,1.5
context,24,0.75,5.0
query,20,0.5,
query,31,0.8,
```

`temperature_c` is the mean outdoor temperature in °C. `occupancy_fraction` ranges from 0 (empty) to 1 (at capacity). For `context` rows, enter the measured cooling energy for that hour in kWh as a nonnegative value in `cooling_kwh`. For `query` rows, leave that field empty and keep the final comma. Include at least one row of each kind.

### Run the task

Open a terminal in the working folder and run:

```sh
python cooling-context.py readings.csv
```

### Interpret the output

The script prints JSON:

```json
{
  "base_temperature_c": 18.0,
  "feature_names": [
    "cooling_degrees_c",
    "occupancy_fraction"
  ],
  "X_context": [
    [
      0.0,
      0.25
    ],
    [
      6.0,
      0.75
    ]
  ],
  "y_context": [
    1.5,
    5.0
  ],
  "X_query": [
    [
      2.0,
      0.5
    ],
    [
      13.0,
      0.8
    ]
  ]
}
```

Each feature row contains degrees above 18 °C (zero below that reference), then occupancy. For example, 24 °C becomes 6 cooling degrees. `X_context` and `y_context` match row for row; use them together as labeled examples. `X_query` contains features for the hours to predict. This example uses a fixed 18 °C reference; check that it suits your building before reusing these features.
